# 实现计划

- 该项目基于msvc v141_xp开发。
- 该项目只需要支持x86，不需要支持x64。

参考框架实现: https://github.com/HaoJun0823/GodEaterModLoader （本地仓库：G:\Projects\GodEaterModLoader）
非官方补丁: https://github.com/Basssiiie/cultures-saga-patches
原架构实现: https://github.com/HaoJun0823/CulturesGameModProject （本地仓库：G:\Projects\CulturesGameModProject）

## CulturesProxyDLL

按照G:\Projects\CulturesGameModProject\Cultures_Proxy实现dll hook，提供dll_proxy.ini用于按照顺序挂载dll（参考G:\Projects\GodEaterModLoader\GodEaterDInputProxy）。

## CulturesGameExtend

- 参考 G:\Projects\GodEaterModLoader\GodEaterExtend 的Features功能实现。
- 将 https://github.com/Basssiiie/cultures-saga-patches 的py补丁单独做一个ini管理，以实现不修改游戏二进制文件的情况下动态注入修改patches。

- 原版游戏多个函数都可以被call来调用，该项目在配合逆向后可声明并调用
